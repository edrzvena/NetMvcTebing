# UI v2 (Adventure Hangat) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganti tampilan Tebing dari versi 1 yang kaku ke versi 2 "adventure hangat": banner carousel, rail kartu yang bisa digeser, chip pulau, kartu foto-forward, header foto di detail gunung, halaman akun terbelah, dan pembatas section bentuk punggungan gunung.

**Architecture:** Logika pilih-pilih data (pulau, banner, rail, tagline) dibikin **pure static class** di `Common/` biar bisa dites tanpa database, lalu dipanggil dari `MountainService`. Tampilan dipecah jadi partial kecil di `Views/Shared/` (carousel, rail, chip, ridge, ikon, stat tile) yang dirakit di view halaman. Interaksi carousel cuma 1 file vanilla JS; geser tetap jalan tanpa JS (CSS scroll-snap).

**Tech Stack:** ASP.NET Core MVC (.NET 10), Razor, Bootstrap 5.3.3 (tanpa build step), EF Core + SQL Server, xUnit (baru), Playwright-style UI check lewat skill `browser-automation`.

**Spec:** `docs/UI_UX.md` (versi 2). Baca bareng plan ini — nilai token, ukuran, copy, dan aturan detail ada di sana; plan ini nunjuk ke nomor section-nya (§).

## Global Constraints

- Bootstrap 5.3.3 dari `wwwroot/lib/bootstrap`, tanpa SASS/npm/build step; kustomisasi lewat CSS variable di `wwwroot/css/site.css`.
- Semua warna di `.cshtml` lewat class Bootstrap / variable `--tb-*` — **gak ada hex di `.cshtml`**.
- Token persis §3.1, §3.3, §3.7 (mis. `--tb-primary: #1F5F4A`, `--tb-forest: #123A2D`, `--tb-accent: #E08A2E`, `--tb-body-bg: #F6F3EE`, `--tb-radius: 10px`, `--tb-radius-lg: 16px`).
- Font: Plus Jakarta Sans, file `@fontsource-variable/plus-jakarta-sans@5.3.0/files/plus-jakarta-sans-latin-wght-normal.woff2` (27 KB) + `LICENSE` (OFL), self-host di `wwwroot/lib/fonts/plus-jakarta-sans/`.
- Ikon: path dari `lucide-static@1.47.0` (ISC, sertakan komentar lisensi di sprite), disatuin ke `wwwroot/images/icons.svg`.
- Gak ada request ke domain lain dari halaman mana pun (font, ikon, library — self-host).
- JS baru cuma `wwwroot/js/carousel.js` (≤ 5 KB, vanilla, tanpa library). Carousel **tanpa autoplay**.
- Budget §9: foto layar pertama Home ≤ 500 KB, font ≤ 100 KB, dekorasi ≤ 8 KB/halaman, CLS ≈ 0.
- `prefers-reduced-motion: reduce` mematikan semua transisi & smooth scroll (§3.6).
- Copy: Bahasa Indonesia santai-sopan, "kamu", Masuk/Daftar/Keluar, tanpa emoji (§6).
- Maks 1 `btn-primary` kelihatan per layar; maks 3 pembatas punggungan per halaman termasuk yang ke footer (§4.15).
- **Jangan `git commit`** — user commit sendiri. Langkah "Checkpoint" = laporin ke user + kasih saran pesan commit.
- Prasyarat: migration `AddMountainImages` udah jalan di DB dev (`dotnet ef database update`).

## Review Focus

1. **Gunung tanpa foto** (Bawakaraeng, Klabat, Welirang, atau upload yang dihapus) → gak pernah masuk banner; kartu tampil placeholder ikon; header detail jadi blok hijau gelap; panel foto halaman akun jatuh ke blok hijau + kontur. Dites di Task 2 (`Featured_SkipsMountainsWithoutPhoto`) & Task 6/9/10 (UI check).
2. **Nama provinsi gak standar** (`" jawa barat "`, `"DKI Jakarta"`, `"Papua Pegunungan"`, `"Provinsi Antah"`) → cocok tanpa peduli huruf besar/spasi; yang gak dikenal = `null`, tetap muncul di "Semua" tapi gak di chip mana pun. Dites di Task 1.
3. **Data sedikit/kosong** (DB baru, < 5 gunung punya foto, rail tanpa isi) → banner render sebanyak yang ada (titik = jumlah slide), banner gak dirender kalau 0, rail kosong gak dirender. Dites di Task 2 & Task 7.
4. **`Description` aneh buat tagline** (null, kosong, tanpa titik, angka `2.958`) → null kalau kosong; tanpa titik = seluruh teks; titik desimal gak dianggap akhir kalimat. Dites di Task 2.
5. **Carousel di ujung & keyboard/reduced-motion** → panah ‹ disabled di awal, › disabled di akhir; Tab ke link di slide yang gak kelihatan bikin slide itu ke-scroll; dengan reduced-motion `scroll-behavior` jadi `auto` & transisi mati. Dites di Task 7.

## Cara jalanin test

- **Unit test:** `dotnet test tests/Tebing.Tests` → semua PASS.
- **UI check:** app jalan di `http://localhost:5181` (`dotnet run --launch-profile http`; matikan dulu sesi Rider kalau port/`bin` kepake), lalu
  `node <dir skill browser-automation>/browser.mjs http://localhost:5181/ --script tests/ui/<file>.mjs`.
  Tiap script `export default async function run(page)` dan **return** `{ pass: boolean, failures: string[] , ... }`.
  "PASS" = output JSON berisi `"pass": true` dan bagian `console errors` & `requests failed` kosong.
  Helper bersama di `tests/ui/_assert.mjs`: `export function check(failures, cond, msg)` (push `msg` kalau `cond` false).
